# Optical Illusion Generator

Generate visual patterns that create optical illusions.

## Goal

Create patterns like moiré effects, impossible shapes, motion illusions.

## Patterns to Try

- Concentric circles (moiré)
- Alternating stripes with rotation
- Checkerboard with perspective distortion
- Scintillating grid
- Animated rotation for motion illusions

## Dependencies

- stb_image_write for saving
- Optional: SFML for real-time animation

## Next Steps

1. Generate stripe patterns
2. Add rotation/scaling transforms
3. Create concentric circle patterns
4. Animate for motion effects (rotating, pulsing)

## Compile

```
g++ main.cpp -o illusions
```
