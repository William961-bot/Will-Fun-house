# Creative Coding C++ Workspace

A collection of experimental C++ projects for image, audio, and visual manipulation.

## Projects

- **image-manipulator** - Basic image loading and pixel manipulation
- **datamosh-glitch** - Glitch art through pixel corruption
- **gif-generator** - Create GIFs from image sequences
- **optical-illusions** - Generate visual patterns and illusions
- **audio-glitch** - Audio file manipulation and effects
- **simple-viewer** - Minimal image display window

## Philosophy

Starter code only. No full implementations. Hackable and educational.

## Building

Each project is independent. Typical compile:
```
g++ main.cpp -o output
```

Add flags as needed for libraries (e.g., `-lsfml-graphics -lsfml-window -lsfml-system`).
